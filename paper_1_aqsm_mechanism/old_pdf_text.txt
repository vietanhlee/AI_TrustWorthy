1. Introduction
Real-time object detection represents the perceptual core of cyber-physical systems,
autonomous mobile robots (AMR), and edge video analytics [1, 2].

For over a decade,

convolutional neural network (CNN) detectorsnotably the You Only Look Once (YOLO)
series [3, 4] and Single Shot MultiBox Detector (SSD) [5]have served as the standard
choice for edge deployments. Despite extensive engineering optimization, convolutional
detectors are fundamentally tied to heuristic Non-Maximum Suppression (NMS) postprocessing.

Because NMS relies on pairwise bounding box comparisons whose runtime

scales quadratically with box density, it introduces non-deterministic execution delays and
creates a prominent attack surface for computational sponge attacks such as Overload [6]
and Phantom Sponges [7].
Detection Transformers (DETR) [8] introduced a paradigm shift in computer vision
by reframing detection as direct set prediction. By coupling multi-head attention with
bipartite Hungarian matching, DETR processes a xed set of learnable object queries in
parallel, completely eliminating heuristic anchor tuning and NMS post-processing. Building upon Deformable DETR [9], Zhao et al. [10] introduced the Real-Time DEtection
TRansformer (RT-DETR). By introducing an intra-scale feature interaction module, a
cross-scale feature fusion encoder, and a multi-layer deformable attention decoder, RTDETR achieves or exceeds the accuracy and inference throughput of state-of-the-art convolutional detectors on edge GPUs and embedded devices. Because RT-DETR processes
a xed query population (Nq

= 300) without downstream NMS ltering, it eliminates

computational runtime volatility under dense proposals. However, this architectural design also implies that adversarial false-positive proposals generated by corrupted queries
are surfaced directly without spatial deduplication, creating a distinct threat landscape.
However, the rapid migration from convolutional backbones to Transformer architectures introduces uncharted adversarial vulnerabilities. While conventional CNN attacks
manipulate anchor grid predictions [11, 12, 13], RT-DETR introduces an architectural
interface that is fundamentally distinct from both CNNs and vanilla DETR:

dynamic

query selection. Rather than using xed, static query embeddings, RT-DETR's hybrid

encoder evaluates Ncand = 2100 candidate anchors across multi-scale feature maps and
selects the top-Nq (Nq = 300) highest-condence proposals to serve as the initial reference
points and content queries for the deformable decoder.
In this paper, we systematically investigate

how this dynamic query selection inter-

face shapes RT-DETR's internal failure modes compared to end-to-end detection loss
attacks and output-space suppression.

Rather than merely showing that RT-DETR is

vulnerablean expected property shared with object detectors broadlyour objective is
to isolate the exact architectural failure mechanisms across encoder feature scales, top-K
query selection, and deformable attention sampling so as to inform future intrinsic defenses. Optimizing an adversarial ranking margin loss at the encoder-decoder boundary
(AQSM) demotes legitimate foreground proposals and collapses COCO-style mAP@50
(evaluated on a representative N = 300 val2017 cohort) from 50.59% to 1.23% (−97.6%,
and mAP@50:95 from 27.93% to 0.56%) via coupled memory distortion and severe spatial
target misrouting rather than simple attention entropy attening.
As conceptualized in Figure 1, RT-DETR routes multi-scale encoder representations
through a dynamic selection bottleneck to initialize decoder queries. When subjected to
adversarial manipulation (such as AQSM), this ranking is inverted: legitimate foreground
anchors are evicted below rank #300, and the resulting decoder cross-attention points are
misrouted onto irrelevant background regions.

2. Background and Related Work
2.1. Architectural Evolution: From CNNs to RT-DETR
Real-time object detection on edge hardware traditionally relied on anchor-based convolutional networks [2, 3, 4]. While these architectures provide low latency, their reliance
on hand-crafted anchor boxes and Non-Maximum Suppression (NMS) creates notable
operational bottlenecks. Pairwise IoU comparisons in NMS exhibit non-deterministic execution times scaling quadratically with the number of generated proposals. This property
has been exploited by computational sponge attacks [6, 7], which ood feature maps with
overlapping candidate boxes to stall real-time edge processing.
Detection Transformers (DETR) [8] eliminated NMS by reframing detection as direct
bipartite matching between

Nq object queries and ground truth objects.

Deformable

DETR [9] reduced the quadratic complexity of global self-attention by sampling localized keys around reference points across multi-scale feature maps.

Building on these

foundations, Zhao et al. [10] introduced RT-DETR, which incorporates an ecient hybrid encoder (separating intra-scale interaction from cross-scale fusion) and a multi-scale
deformable decoder.

A dening hallmark of RT-DETR is its dynamic query selection

mechanism: instead of initializing queries from static learnable embeddings, the encoder
generates Ncand

= 2100 candidate anchors and selects the top-Nq (Nq = 300) highest-

scoring proposals to initialize the decoder. Because RT-DETR processes a strictly xed
query population of 300 tokens without NMS post-processing, it structurally neutralizes
NMS-targeted computational latency attacks.

2.2. Adversarial Attacks on Object Detectors
Adversarial attacks on computer vision exploit the locally linear vulnerability of deep
neural representations [14, 15, 16]. While early attacks focused on classication models,
attacking multi-task object detectors requires manipulating spatial bounding box coordinates, foreground/background condence scores, and multi-class categorization logits
simultaneously.
In convolutional detectors, Xie et al. [11] proposed Dense Adversarial Generation
(DAG) to suppress object proposals, while Wang et al. [13] introduced Daedalus to exploit
the Non-Maximum Suppression (NMS) stage. Liu et al. [17] and Lee et al. [12] demonstrated adversarial patch attacks that disguise targets from proposal-based models. In the
context of vision transformers, Gu et al. [18] analyzed the vulnerability of self-attention
representations to localized perturbations. For transformer-based object detectors, Nazeri
et al. [19] evaluated adversarial robustness across vanilla DETR and Deformable DETR
architectures, while Jayasundara et al. [20] and Wang et al. [21] investigated attentiondisruption and localized query manipulation strategies.
Crucially, however, these prior studies investigated models where decoder queries are
N ×d
initialized from

static learnable embeddings

that remain identical across all input images prior to decoder cross-attention. In standard
DETR [8], an attacker cannot displace which queries are admitted because all Nq queries
are evaluated unconditionally by design.

While Deformable DETR [9] improves multi-

scale attention eciency, it still decouples query existence from dynamic encoder proposals.
Furthermore, while modern DETR variants like DINO [22] employ two-stage selection,
they integrate contrastive denoising training and static positional anchors to stabilize
query-to-object bipartite matching.

Understanding how this architectural coupling dictates failure modes under adversarial
perturbation is essential to designing intrinsically robust detection transformers for autonomous robotics.

4.1. Dataset and Benchmark Cohort
All experiments are benchmarked on images drawn from the ocial Microsoft COCO
2017 validation set (val2017, 5,000 images) [25].

To support computationally inten-

sive gradient-based adversarial optimization alongside paired repeated-measures causal
surgery and multi-layer attention telemetry, we establish a standardized evaluation cohort of N = 300 images. This cohort was extracted via stratied random sampling with
a xed deterministic seed (seed=42) to mirror the category distribution and scale density
of the full dataset.

Among the 300 images, 297 contain valid non-crowd ground-truth

objects (> 2,000 labeled bounding box instances across 78 active categories), enabling
rigorous paired repeated-measures statistical testing (df

= [1, 296]). Ground-truth-free

scenes (N = 3) are excluded exclusively from instance-level paired surgery but retained
in global precision-recall integration.

4.2. Target Architecture and Edge Computing Platform
We target the ocial pre-trained RT-DETR-R18VD (320×320 resolution), comprising
a ResNet-18 VD backbone, a hybrid cross-scale feature fusion encoder, and a 3-layer
deformable attention decoder. Inference and latency measurements are benchmarked in
PyTorch FP32 on an edge-class mobile workstation platform powered by an Intel Core
i5-12600H CPU (12 cores, 16 threads, 45W base TDP) and a mobile NVIDIA GeForce
RTX 3060 Laptop GPU (6GB GDDR6, 80W TGP). This hardware class directly models
onboard computing payloads deployed in autonomous mobile robots (AMRs), automated

6.2. Threats to Validity: Dataset Constraints and Real-World Edge Deployments
We explicitly acknowledge four methodological threats to validity that bound our
empirical conclusions:
1.

Single Architecture and Backbone Scope: Our experiments focus primarily

on the ocial RT-DETR-R18VD model at 320 × 320 resolution. While the mathematical formulations of multi-scale top-K selection and deformable decoder crossattention are structurally shared across all RT-DETR variants (e.g., RT-DETR-R50,
R101, and HGNetv2 backbones), larger backbones possess greater representation
capacity that may alter quantitative eviction ratios.

We treat our blueprint as a

veried design hypothesis for real-time edge DETRs, highlighting the necessity of
future multi-backbone cross-validation.
2.

Benchmark Dataset Distribution Constraints: A notable limitation of stan-

dard benchmark datasets like COCO is the near-total absence of empty scenes
(images devoid of foreground objects). In practical edge surveillance or autonomous
driving at night, cameras frequently encounter completely empty scenes where the
true active query count is zero. On such images, a clean input naturally produces

ract = 0, overlapping identically with the signature of a Query Vanishing attack.
Practical implementations must incorporate spatio-temporal video tracking or background priors to contextualize zero-detection frames.

3.

White-Box Access and Physical-World Transferability: Our mechanistic
evaluation assumes white-box access with exact gradient backpropagation through
the hybrid encoder. While this represents the standard worst-case security evaluation protocol in adversarial robustness, physical-world deployments may encounter
input quantization, camera ISP noise, or black-box query constraints. Investigating
physical patch transferability and query-limited optimization against the dynamic
selection interface represents an important open avenue.

4.

Hardware Platform Class and Ultra-Low-Power Edge Constraints: Our

empirical latency and throughput evaluations are benchmarked on an edge-class
mobile workstation platform (45W80W TDP), representing onboard computing
units in mobile robotics and industrial edge servers. However, safety-critical edge
sensing is also deployed on ultra-low-power microcontrollers and embedded NPUs
(e.g., Google Coral Edge TPU, Raspberry Pi 5, STM32,

< 5W15W TDP). On

such deeply embedded hardware, memory bandwidth is severely constrained, and
INT8/INT4 quantization is mandatory.

Investigating whether quantization inter-

acts with dynamic query selection vulnerability on ultra-low-power edge NPUs represents an important direction for future research.
