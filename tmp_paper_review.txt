  Decomposing Failure Modes of Real-Time DETR under Encoder Adversarial
                  Attacks: An Empirical Diagnostic Study




Abstract
Real-Time Detection Transformers (RT-DETR) eliminate Non-Maximum Suppression (NMS) via bipartite matching
and dynamic top-K query selection atop a multi-scale hybrid encoder. Because proposal selection operates directly
on encoder feature pyramids, white-box encoder perturbations simultaneously corrupt memory representations and
query routing. We present an empirical diagnostic study on COCO val2017 (native 640 × 640, S = 8, 400 tokens,
ℓ∞ budget ϵ = 16/255) analyzing RT-DETR-R18VD (3 decoder layers, N = 300), cross-depth verification on
RT-DETR-R50VD (6 decoder layers, N = 200), and a unified six-architecture benchmark (N = 300) using
Adversarial Query Selection Manipulation (AQSM) within a 2 × 2 factorial tensor-swap protocol, tripartite loss
ablations, pixel-space controls, and external attention/CNN baselines.
    Our measurements establish four main observations: (1) Protocol-Level and Pixel-Space Failure Decom-
position: AQSM collapses COCO mAP@50 from 66.93% to 4.05% cached / 3.85% tripartite ablation on R18VD
(5-seed fresh 4.00 ± 0.74%) and from 74.45% to 10.15% / 8.78% on R50VD (5-seed 8.53 ± 0.88%), whereas calibrated
Gaussian noise (σ = 16/255) preserves 62.39% and 71.93%. Under our 2 × 2 tensor-swap protocol, encoder memory
corruption accounts for 60.6%–71.4% of operational attribution on R18VD (Nvalid = 299) and 68.2%–74.9% on
R50VD (N = 200); pixel-space controls independently confirm that isolating query selection leaves 59.07% R18VD
/ 68.67% R50VD intact whereas pure memory disruption collapses accuracy to 0.00%. (2) Attention Invariance
vs. Spatial Misrouting: Normalized deformable attention entropy remains statistically equivalent around ≈ 0.80
within ±0.02 TOST bounds (0.8032 → 0.7945 on R18VD, pTOST = 3.46 × 10−5 ; 0.8150 → 0.8087 on R50VD,
pTOST = 6.80 × 10−6 ), whereas reference drift drops sampling foreground hit rate (63.53% → 45.44% R18VD;
64.77% → 50.24% R50VD) across AQSM, Vanishing, Task PGD, and center-only shift controls. (3) Fixed-Query
Latency Invariance: Timed via CUDA events across 20 interleaved images on NVIDIA Tesla T4 (PyTorch
FP32), RT-DETR sustains invariant latency from clean inputs to 154-box sponge flooding (36.60 → 36.37 ms on
R18VD; 74.48 → 74.63 ms on R50VD), running 3.8× faster than RetinaNet-R50-FPN-v2 (139.73 → 140.36 ms)
without candidate-cap heuristics. (4) Defense Limits and Generalization: Individual runtime monitors (ESM,
SCM, BCM) suffer 84%–99% raw adaptive bypass, while an ensemble forces 0.00%–0.48% joint evasion at higher
residual mAP (9.51%–10.00% R18VD). Crucially, even logit-calibrated, encoder-sampled zero-shot Static Query
Augmentation (SQA) fails to recover detection (4.03% R18VD / 10.27% R50VD), confirming that encoder represen-
tation co-hardening is prerequisite across vulnerable dynamic two-stage DETR families (RT-DETR, RT-DETRv2,
and Deformable DETR).
Keywords: Real-Time Detection Transformer, Adversarial Robustness, Dynamic Query Selection, Interventional
Activation Patching, Edge AI Telemetry, Static Query Augmentation


1. Introduction

    Real-time object detection forms the perceptual foundation of cyber-physical edge systems, automated guided
vehicles (AGV), autonomous mobile robots (AMR), and intelligent video infrastructure [1, 2]. For over a decade,
convolutional neural network (CNN) detectors—notably the You Only Look Once (YOLO) family [3, 4, 5] and
Single Shot MultiBox Detector (SSD) [6]—have dominated edge deployments. Despite architectural maturity,
convolutional detectors rely intrinsically on Non-Maximum Suppression (NMS) post-processing [7, 8]. Because
pairwise IoU filtering in NMS scales quadratically with surviving candidate density, dense proposal-flooding
("sponge") attacks [9, 10, 11] can induce severe data-dependent latency spikes.
    Detection Transformers (DETR) [12] reframed object detection as direct bipartite set prediction [13], processing
a fixed budget of object queries in parallel without anchor clustering or NMS. Building on Deformable DETR
[14], Zhao et al. [15] introduced the Real-Time DEtection TRansformer (RT-DETR), pairing an efficient hybrid
encoder (decoupling intra-scale attention from cross-scale fusion) with a multi-scale deformable decoder. While
two-stage Deformable DETR [14] and DINO [16] also initialize queries from top-K encoder proposals, RT-DETR
removes NMS post-processing completely and evaluates a fixed Nq = 300 decoder budget for deterministic real-time
execution. Because those Nq = 300 content and coordinate priors are routed directly from encoder feature pyramids,
however, the encoder-decoder boundary couples feature memory representations tightly to query routing.
    This coupling introduces distinct security trade-offs compared with convolutional anchor/NMS attacks [17, 18, 19]
or vanilla static-query DETR attacks [12, 20]. RT-DETR’s hybrid encoder scores S = 8, 400 anchors across multi-

2. Background and Related Work

2.1. Architectural Evolution: From CNNs to RT-DETR
    Real-time object detection on embedded and edge platforms has historically relied on convolutional architectures
[1, 2, 3, 6, 4]. While CNN detectors achieve high throughput, dense candidate grids and Non-Maximum Suppression
(NMS) [7, 8] introduce quadratic pairwise IoU complexity as survivor counts grow, creating a well-documented
latency attack surface via computational sponge flooding [9, 10, 11].
    Detection Transformers (DETR) [12] eliminated NMS by formulating detection as direct bipartite matching
between a fixed set of object queries and ground-truth instances via the Hungarian algorithm [13]. Deformable
DETR [14] resolved slow convergence and dense global attention complexity via sparse multi-scale deformable
sampling around learnable reference points, introducing top-K encoder proposal selection in its two-stage variant.
Building on this paradigm, Zhao et al. [15] proposed RT-DETR, coupling an efficient hybrid encoder with a
deformable decoder: the encoder scores S = 8, 400 anchors across three feature scales and routes the top-Nq
(Nq = 300) proposals directly into the decoder without NMS post-processing. While this fixed-query structure
eliminates proposal-count-dependent NMS latency overhead in inference, runtime stability under system-level
contention or dynamic batching still depends on deployment engineering.

2.2. Adversarial Attacks on Object Detectors
    Adversarial examples exploit gradient sensitivity across classification, localization, and proposal scoring heads
[22, 23, 24, 25]. Classical CNN attacks suppress proposals or overwhelm NMS clustering via dense gradients
(DAG [17], Daedalus [19], physical patches [18], and TOG [26]). Within transformer vision architectures, Gu et
al. [27] studied attention sensitivity, Nazeri et al. [20] benchmarked DETR and Deformable DETR robustness, and
Jayasundara et al. [21] alongside Wang et al. [28] explored attention disruption and localized query perturbations.


                                                         3
    Unlike vanilla DETR [12], where static learnable query embeddings θq ∈ RNq ×d enter the decoder unconditionally,
or two-stage CNN RPNs [1] followed by NMS, RT-DETR routes both content embeddings and initial bounding
boxes straight from encoder top-K selection (while DINO’s contrastive denoising training groups [16] are employed
during training to stabilize bipartite matching, they are discarded at inference, leaving test-time decoding dependent
entirely on dynamic query selection). Rather than claiming novelty in the existence of top-K selection itself, our
contribution isolates how perturbations at this 8, 400-to-300 bottleneck interact with multi-scale encoder memory
and multi-layer deformable decoding in RT-DETR-R18VD and RT-DETR-R50VD—informing related non-NMS
designs such as RT-DETRv2 [29] and D-FINE [30].

3. Threat Model and Adversarial Formulations
3.1. Adversarial Goals, Knowledge, and Capabilities
    We operate under a standard white-box threat model following established robustness evaluation principles [31]:
  • Adversary Goals: The primary objective is false-negative object evasion while avoiding both complete
    zero-box blackouts (characteristic of output-logit suppression) and extreme false-alarm flooding (characteristic
    of unconstrained Task PGD), without altering execution latency. We evaluate ϵ = 16/255 as a canonical
    high-severity stress budget alongside lower budgets (ϵ ∈ {4, 8}/255 in Section 5.8) rather than as a perceptual
    imperceptibility benchmark.
  • Adversary Knowledge: The adversary possesses complete white-box access to network weights θ, hybrid
    encoder layers, proposal selection heads, and decoder parameters.
  • Adversary Capabilities: Pixel perturbations are constrained under an ℓ∞ ball:

3.2. Adversarial Threat Taxonomy Across Detection Paradigms
    To contextualize encoder selection vulnerabilities across object detection paradigms, we organize threats into
three tiers (Figure 2):
  1. Tier A: Conventional CNN Detectors (Dense Candidate Heads and NMS): Single-stage and anchor-
     based CNN detectors [1, 2] expose dense spatial grids and NMS post-processing to objectness suppression
     (TOG [26]) and quadratic NMS sponge flooding [9, 19, 10, 11].
  2. Tier B: Decoder Output-Space DETR Attacks (Logits and Bipartite Loss): End-to-end transformer
     attacks operate through the full decoder stack, either suppressing top decoder confidences (Query Vanishing,
     reducing active detections at τ = 0.35 on held-out test splits to 0.74 ± 1.05 on R18VD [Ntest = 210] and
     1.20 ± 1.26 on R50VD [Ntest = 140] vs. clean 8.54 ± 9.06 and 8.64 ± 8.14) or inverting Hungarian bipartite
     matching loss (Standard Task PGD [20]), inflating dense clutter (46.43 ± 19.91 active boxes on R18VD and
     34.65 ± 15.54 on R50VD).
  3. Tier C: Encoder Query Selection Probe (AQSM): Tailored to dynamic top-K architectures, AQSM
     backpropagates exclusively from the intermediate 8, 400-to-300 encoder selection head, evicting clean fore-
     ground priors while maintaining intermediate active-box counts (17.68 ± 11.14 on R18VD and 13.94 ± 9.76
     on R50VD at τ = 0.35; less than half of Task PGD clutter).

4. Experimental Setup and Benchmark Protocol

4.1. Dataset and Cohort Alignment Protocol
    All experiments evaluate MS COCO 2017 validation (val2017, 80 classes) [32] at native 640 × 640 resolution
(S = 8, 400 spatial tokens: 802 + 402 + 202 ), admitting Nq /S = 300/8, 400 = 3.57% of encoder proposals into the
decoder. To maintain strict intra-model provenance without mixing baseline cohorts across sections, experiments
follow two explicitly scoped cohorts alongside a unified multi-model suite:
   1. Primary RT-DETR-R18VD Cohort (N = 300, Seed 42): Nvalid = 299 scenes contain annotated
      ground-truth objects (dferr = 298 for paired ANOVA/Wilcoxon tests; power 0.8112 at d = 0.20, > 0.9999 at
      d = 0.50, α = 0.01), with disjoint monitor splits Ncal = 90/Ntest = 210 in Section 6. Note that Tasks 3, 4, 6,
      8, and 11 use a refreshed deterministic Seed 42 cache (AQSM mAP@50 3.85%–4.08%) paired with Tasks 1, 2,
      5, and 10 (4.05%) on identical N = 300 clean scenes (66.93% baseline); minor inter-run deltas fall well inside
      the 5-seed variance (4.00 ± 0.74%).
   2. Cross-Depth RT-DETR-R50VD Cohort (N = 200, Seed 42): All R50VD diagnostic tasks (0–11) share
      a single unified cache across the first N = 200 scenes (Nvalid = 200, dferr = 199, clean mAP@50 = 74.45%),
      partitioned into Ncal = 60/Ntest = 140 for telemetry monitors and adaptive evasion.
   3. Unified Cross-Architecture Cohort (N = 300): Section 7.2 evaluates all six detector architectures
      (including RT-DETR-R50VD at 72.95% clean mAP@50 on N = 300) identically side by side.

4.2. Target Architectures and Compute Environment
    We evaluate official pretrained checkpoints from HuggingFace transformers and torchvision: (1) RT-DETR-
R18VD (PekingU/rtdetr_r18vd, 20M params, 3 decoder layers); (2) RT-DETR-R50VD (PekingU/rtdetr_r50vd,
42M params, 6 decoder layers); and, in Section 7.2, RT-DETRv2-R18VD, two-stage Deformable DETR, static
Vanilla DETR-R50, and RetinaNet-R50-FPN-v2. All accuracy, surgery, telemetry, defense, and CUDA-event
FP32 latency benchmarks execute in PyTorch on NVIDIA Tesla T4 GPUs (CUDA Capability 7.5; peak allocated
VRAM 2, 608.92 MB for R18VD and 2, 824.89 MB for R50VD during interleaved profiling). Stage timing averages
Nruns = 300 (R18VD) / 200 (R50VD) CUDA iterations after warm-up, while condition timing uses Nruns = 100
iterations interleaved randomly across 20 distinct COCO scenes.

5.9. Operational Hardware Execution Latency and Interleaved CNN+NMS Comparison
    Table 10 reports exact CUDA-event PyTorch FP32 stage timing (Nruns = 300 R18VD / 200 R50VD) and
randomly interleaved 20-image adversarial vs. proposal-flooding sponge latency (Nruns = 100) on NVIDIA
Tesla T4, benchmarked directly against a pretrained RetinaNet-R50-FPN-v2 (CNN+NMS) baseline under
identical 20-image interleaved conditions.
    By fixed-query Nq = 300 decoding, Dynamic Query Selection accounts for just 1.61 ± 0.07 ms (4.36%) on
R18VD (36.99 ± 0.99 ms total, 27.04 FPS) and 1.76 ± 0.08 ms (2.34%) on R50VD (75.31 ± 1.42 ms total, 13.28 FPS),
while Backbone and Hybrid Encoder consume 78.20%–80.60% of runtime. Across 20 distinct interleaved scenes,
proposal-flooding sponge stress elevates active outputs from 7.95 → 154.20 boxes on R18VD (19.4×) and from
7.60 → 116.00 boxes on R50VD (15.3×), yet end-to-end GPU latency stays completely invariant: 36.60 ± 0.95 ms
clean vs. 36.47 ms AQSM, 36.47 ms Task PGD, and 36.37±0.96 ms Sponge on R18VD (27.50 FPS); and 74.48±0.93
ms clean vs. 74.72 ms AQSM, 74.72 ms Task PGD, and 74.63 ± 1.01 ms Sponge on R50VD (13.40 FPS). Under
the identical interleaved GPU protocol, RetinaNet-R50-FPN-v2 also maintains tight latency (139.73 → 140.36
ms, +0.45%, post-NMS boxes 101.3 → 181.9 on the R18 runner; 141.78 → 142.18 ms, +0.28% on the R50
runner) because modern torchvision GPU batched NMS imposes fixed candidate caps (topk_candidates=1000,
detections_per_img=300)—distinct from uncapped legacy NMS pipelines cited in prior sponge studies [9, 10, 11].
Nevertheless, RT-DETR achieves 3.8× lower latency than RetinaNet-R50-FPN-v2 while enforcing fixed-tensor
determinism without heuristic candidate truncation.

via Static Query Augmentation (SQA) across both raw uncalibrated and logit-calibrated, encoder-sampled
configurations. Following adaptive security evaluation standards [31, 36], every watchdog and SQA variant is
evaluated against both stationary attacks and true white-box adaptive adversaries across full held-out test splits.

   1. Adaptive ESM Evasion: Optimizing Eq. (11) drops ESM TPR to 2.38%–4.76% (95.24%–97.62% raw

      R18VD (2.80%–4.98% on R50VD), achieving 48.57%–54.76% full joint evasion (simultaneous monitor bypass
      and detector collapse).
   3. Adaptive BoxCountMonitor (BCM) Evasion: Adding soft cardinality clamping leaves BCM bypassed on
      84.29%–92.86% of R18VD scenes (91.43%–94.29% on R50VD) while driving active boxes cleanly down to

      success drops to 0.00%–0.48%, illustrating the steep attack-fidelity cost imposed by coupled telemetry

6.3. Negative Empirical Result: Calibrated vs. Uncalibrated Static Query Augmentation (SQA)
    To test whether bypassing dynamic encoder ranking stabilizes detection when coordinate calibration and encoder
feature sampling are properly applied, we evaluate Static Query Augmentation (SQA, Nstatic = 30 uniform grid
anchors over [0.12, 0.88]2 , Nq = 330) across three architectural configurations (Figure 9(c) and Table 12): (1) Raw
Uncalibrated + Gaussian Noise (static_boxes injected without logit transform); (2) Logit-Calibrated +
Gaussian Noise (applying inverse-sigmoid transformation logit(b) so first-layer decoder σ(·) hits exact canvas
grid coordinates); and (3) Logit-Calibrated + Encoder Feature Sampling (bilinear/RBF spatial sampling
directly from encoder output memory M at grid coordinates instead of uninformative N (0, 0.022 ) noise), alongside
Dynamic Top-330, Random-30, and full held-out adaptive attacks (Ntest = 210 R18VD / 140 R50VD).
    Crucially, even after eliminating center-clustering via torch.logit calibration and providing real spatial features
via encoder memory sampling, zero-shot SQA still yields an unambiguous null recovery result across both depths:
on R18VD (N = 300), stationary AQSM baseline 4.08% shifts to 3.98% (raw+noise), 4.01% (logit+noise), and
4.03% (logit+encoder_sample, −0.05 pp); on R50VD (N = 200), 10.15% shifts to 10.10%, 10.29%, and 10.27%
(+0.12 pp). Under full held-out white-box adaptive evasion against the calibrated, encoder-sampled SQA model
(Ntest = 210/140), accuracy drops further to 2.65% on R18VD (96.04% bypass) and 6.66% on R50VD (91.06%
bypass). Because causal surgery (Section 5.3) proved that encoder memory Madv loses semantic fidelity (Arm Cfull
retains only 9.31% / 15.46%), zero-shot static queries querying corrupted memory cannot reconstruct objects
without joint representation-level adversarial training.

 7. Discussion, Generalization, and Threats to Validity

 7.1. Geometric Receptive Gating at the Encoder-Decoder Interface
     Across both R18VD (N = 300) and R50VD (N = 200), RT-DETR routes 3.57% of encoder proposals (300/8, 400)
 into deformable cross-attention. While clean memory preserves sufficient context that perturbed proposal locations
 retain 58.4% of accuracy on R18VD (Arm Dindex = 39.11%) and 70.9% on 6-layer R50VD (52.82%), corrupting
 encoder memory collapses accuracy to 9.31% and 15.46% even with clean queries (Arm Cfull ). Pixel-space isolation
 controls (Table 1) and calibrated SQA failures (Table 12) independently establish that feature-pyramid integrity is
 the prerequisite for recovery.

7.2. Cross-Architecture Generalization Benchmark
    To assess whether dynamic query-selection vulnerability generalizes beyond RT-DETR-R18VD and R50VD,
Table 13 and Figure 10(b) benchmark six detector architectures on a single unified N = 300 COCO val2017
cohort (640 × 640, ϵ = 16/255, T = 15): (1) RT-DETR-R18VD, (2) RT-DETR-R50VD (evaluated identically at
N = 300, Clean 72.95%), (3) RT-DETRv2-R18VD [29], (4) two-stage Deformable DETR with box refinement [14],
(5) static-query Vanilla DETR-R50 [12], and (6) RetinaNet-R50-FPN-v2 (CNN+NMS).
    Across all dynamic top-K architectures, AQSM inflicts severe collapse with heavy foreground eviction:
RT-DETRv2-R18VD falls from 67.41% to 4.01% (88.21% evicted, cosine 0.4411), two-stage Deformable DETR
falls from 63.10% to 3.99% (88.11% evicted, cosine 0.6063), and RT-DETR-R50VD falls from 72.95% to 8.89%
(77.59% evicted, cosine 0.5773). Conversely, static Vanilla DETR (59.47%) and CNN RetinaNet (63.99%) possess
no dynamic encoder-to-decoder top-K interface (denoted N/A under AQSM), yet still collapse to 0.72% and
0.29% under end-to-end Task PGD while RetinaNet preserves 61.30% under Gaussian noise (σ = 16/255). Thus,
query-selection coupling is an intrinsic vulnerability shared across dynamic two-stage DETR families.

   1. Multi-Seed Reproducibility and Cohort Distinction: Fresh 5-seed AQSM generation (K = 5 inde-
      pendent Cbg draws) converges tightly on both R18VD (N = 300: 4.00 ± 0.74%, range 3.17%–4.75%) and
      R50VD (N = 200: 8.53 ± 0.88%, range 7.67%–9.80%). Explicit separation of R18VD (N = 300), R50VD
      deep diagnostics (N = 200), and the six-model cross-architecture suite (N = 300) eliminates cohort mixing
      while preserving exact intra-model baseline consistency.
   2. OOD Tensor Swaps Mitigated by Pixel-Space Controls: Tensor-swapped Arms C and D create OOD
      states; however, pixel-space Memory-Isolated (59.07% R18VD / 68.67% R50VD) and Pure-Memory (0.00%)
      controls reach identical mechanistic conclusions solely on feasible ℓ∞ images.
   3. Deployment Scope Boundaries: All experiments run in PyTorch FP32 on Tesla T4 GPUs under ℓ∞
      white-box noise. Physical patches, quantized TensorRT/ONNX latency transfer on embedded edge SoCs, and
      adversarially co-trained hybrid encoders paired with SQA priors remain key next-step engineering directions.


8. Conclusion

    We presented an empirical diagnostic study decomposing failure modes of Real-Time DETR on COCO
val2017 (640 × 640, ϵ = 16/255) across RT-DETR-R18VD (N = 300), RT-DETR-R50VD (N = 200), and six
detector architectures (N = 300). Under our 2 × 2 tensor-swap protocol, encoder memory corruption accounts for
operational attribution ranges of 60.6%–71.4% on R18VD and 68.2%–74.9% on R50VD; pixel-space isolation controls
independently confirm this dominance (59.07% / 68.67% memory-isolated vs. 0.00% pure-memory disruption).
Internal telemetry proves via paired TOST testing that normalized cross-attention entropy remains equivalent
near ≈ 0.80 within ±0.02 (pTOST ≤ 3.46 × 10−5 ), whereas coordinate misrouting halves foreground sampling hit
rate and is faithfully reproduced by center-only random shifts. Twenty-image interleaved CUDA profiling verifies
invariant RT-DETR latency under proposal-flooding sponge stress (36.60 → 36.37 ms R18VD; 74.48 → 74.63 ms
R50VD), achieving 3.8× faster throughput than RetinaNet-R50-FPN-v2. Finally, adaptive evasion circumvents all
standalone monitors (84%–99% raw bypass) yet faces a strict multi-channel ensemble trade-off (0.00%–0.48% joint
evasion), and even logit-calibrated, encoder-sampled SQA yields null recovery (4.03% R18VD / 10.27% R50VD),
proving that defending dynamic two-stage DETR families requires joint encoder representation hardening alongside
calibrated static priors.
